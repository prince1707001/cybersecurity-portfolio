# Lab 01 – Wazuh Monitoring with Kali & Ubuntu

## Objective
Monitor lab network activity, detect attacks, and analyze alerts using Wazuh.

## Environment
- Kali Linux: Attacker machine (simulated attacks)
- Ubuntu Server: Wazuh Manager + Agent
- Network: Isolated lab

## Pentesting Simulation
- Performed lab attacks (Metasploitable / Mr Robot)
- Captured traffic with Wireshark
- Simulated suspicious login attempts

## SOC Monitoring
- Installed Wazuh Agent on Ubuntu target
- Monitored logs for brute force, failed login attempts, and network scans
- Alerts triggered on suspicious activity
