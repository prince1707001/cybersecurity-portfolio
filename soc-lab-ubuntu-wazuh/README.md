# SOC Labs – Security Monitoring & Log Analysis

This section documents hands-on Security Operations Center (SOC) exercises performed in a controlled lab environment.

The focus is on detection, monitoring, log analysis, and incident investigation using industry-relevant tools.

---

## Lab Environments

### 1. Wazuh Monitoring Lab
- Ubuntu Server (Wazuh Manager)
- Kali Linux (Attack Simulation)
- Agent-based monitoring
- Real-time alert generation
- Brute force and network scan detection

### 2. Windows Log Analysis with Splunk
- Windows VM (Event Generation)
- Splunk (Log Collection & Analysis)
- Event Viewer log export and indexing
- Security event investigation
- Dashboard creation and search queries

---

## Skills Demonstrated

- Log analysis and event correlation
- Attack detection and alert review
- Windows Security Event investigation
- Brute force detection
- Threat monitoring and response
- SIEM usage (Wazuh & Splunk)

---

## Tools Used

- Wazuh
- Splunk
- Windows Event Viewer
- Wireshark
