# Lab 02 – Windows Event Log Analysis with Splunk

## Objective
Collect, analyze, and review Windows Event Logs in Splunk to detect security-relevant events.

## Environment
- Windows VM: Event generation (Event Viewer)
- Splunk VM: Log collection and analysis
- Network: Isolated lab

## Steps
1. Generated Windows events (login attempts, system changes)
2. Exported or forwarded events to Splunk
3. Indexed logs in Splunk
4. Performed searches and visualizations to identify anomalies
