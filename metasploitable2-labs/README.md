# Metasploitable 2 – Full Penetration Testing Labs

This section documents comprehensive penetration testing exercises performed against the intentionally vulnerable Metasploitable 2 virtual machine in a controlled lab environment.

The engagement covered the full attack surface, with exploitation of multiple exposed services across the network stack.

---

## Scope of Testing

- Network discovery and host identification
- Full port scanning and service enumeration
- Vulnerability identification across exposed services
- Exploitation of misconfigured and vulnerable services
- Man-in-the-Middle and session-based attacks
- Web application security testing
- Post-exploitation validation
- Security impact assessment and mitigation recommendations

---

## Services Assessed & Exploited

- FTP (VSFTPD backdoor)
- SSH (weak credentials)
- Telnet
- SMTP
- HTTP / HTTPS
- MySQL
- Samba
- NFS
- Tomcat
- Distcc
- IRC
- Other legacy and misconfigured services
