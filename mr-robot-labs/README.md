# Mr Robot VM – Full Penetration Testing Report

This section contains a complete penetration testing exercise performed against the Mr Robot vulnerable virtual machine in a controlled lab environment.

## Attack Chain Overview
1. Network discovery (Netdiscover)
2. Port scanning and enumeration (Nmap)
3. Web vulnerability scanning (Nikto)
4. WordPress enumeration
5. Exploitation and privilege escalation
6. Post-exploitation validation

## Tools Used
- Netdiscover
- Nmap
- Nikto
- WPScan
- Metasploit
- Manual web enumeration

## Skills Demonstrated
- Full attack lifecycle execution
- Web application exploitation

- Privilege escalation

All testing was performed legally in an isolated lab environment.
