# Cybersecurity Portfolio – Offensive & Defensive Security

## About Me
I am a hands-on cybersecurity professional with practical experience across both offensive security (Red Team / Penetration Testing) and defensive security (Blue Team / SOC operations).

My learning approach is strongly lab-driven: I build, attack, monitor, and analyze systems in controlled environments to understand how attacks work end-to-end and how they can be detected, mitigated, and prevented.

This portfolio reflects my journey toward becoming a **Purple Team practitioner**, combining attacker mindset with defender visibility.
